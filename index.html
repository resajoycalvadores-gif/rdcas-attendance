QR Code-Based Student Verification and Attendance System

🌿 Welcome to RDCAS

This system registers students, generates a QR code for each student, and records attendance whenever a registered student's QR code is scanned.

Student Registration
Save student ID, full name, and grade/section.
QR Code Generation
Create a QR code connected to the student's ID.
QR Scanner
Scan a registered student's QR code.
Attendance History
Review previous attendance and filter records.

Note: Records are saved in the current browser. Use the same browser and device to access them.
